# Макора

Макора — демонстрационный интерфейс подготовки хакатонного проекта: анализ задания, исследование и идея, план разработки и мок-данные. В интерфейсе используется вымышленный кейс «Тихий кампус»; загруженное условие не анализируется моделью, а демонстрационный план и фикстуры не перестраиваются после изменения идеи.

## Запуск сайта

Из корня репозитория с установленным Python:

```sh
python -m http.server 8000 --directory dist --bind 127.0.0.1
```

Откройте [localhost:8000](http://localhost:8000/). Браузерная API-заглушка использует Service Worker на localhost или HTTPS. Прогресс утверждений и изменения идеи сохраняются в локальном хранилище браузера.

## Скиллы и артефакты

В `skills/` находятся шесть самостоятельных инструкций для этапов 1–4. Они описывают работу агента, но сайт и `makora_core` пока не подключены к модели. Локальное ядро управляет версиями и утверждениями файлов, а также формирует пакет контекста; инструкция — в [docs/agent-foundation.md](docs/agent-foundation.md). Рабочий каталог `workspace/` исключён из Git: не помещайте конфиденциальные документы в публичный репозиторий.

## Проверки

Для Python-проверок установите зависимость и выполните тесты:

```sh
python -m pip install -r requirements-dev.txt
python scripts/check_skills.py
python -m unittest discover -s tests -v
```

В `tests/fixtures/` находятся учебные входы и вручную подготовленные ожидаемые результаты для каждого из шести скиллов. Тесты проверяют форматы и связи между этапами; примеры не являются результатами выполнения ИИ. GitHub Actions запускает проверку структуры скиллов и Python-тесты при push и pull request. Браузерная проверка запускается отдельно.

Скрипт [`tests/browser-flow.js`](tests/browser-flow.js) проверяет демонстрационный маршрут в отдельном браузерном профиле через Playwright CLI. Запустите сайт, затем:

```sh
npx --yes --package @playwright/cli playwright-cli -s=makora-smoke open http://127.0.0.1:8000/
npx --yes --package @playwright/cli playwright-cli -s=makora-smoke run-code --filename tests/browser-flow.js
npx --yes --package @playwright/cli playwright-cli -s=makora-smoke close
```

Сценарий сбрасывает `localStorage` только в созданном профиле Playwright. Проверки фикстур и mock API подтверждают работу демонстрационных данных, а не будущего продукта.
