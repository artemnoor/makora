# Архив документации и проверок

[← Разработка Макоры](development.md) · [README](../README.md)

Эти материалы сохранены для истории разработки. Они описывают состояние на момент написания: прежние номера этапов, встроенный чат, демонстрационный маршрут или старые способы запуска могут не соответствовать текущему приложению.

Для работы сейчас начинайте с [маршрута проекта](workflow.md) и [полного описания этапов](stages.md). Старый успешный прогон не подтверждает работу более поздних изменений; актуальные проверки описаны в [руководстве разработчика](development.md).
