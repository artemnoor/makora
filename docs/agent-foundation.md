# Локальная основа агентной системы

Этот модуль хранит файлы и подготавливает контекст вызова скилла. Вызов модели, запуск агентов и подключение к интерфейсу сайта ещё не реализованы. Существующее демо в `dist/` не использует это хранилище.

Нужен Python 3.9 или новее. Для проверки YAML в первом скилле нужен PyYAML. Рабочую область создавайте вне репозитория или в игнорируемом каталоге: входные материалы могут содержать приватные сведения.

```sh
python -m makora_core init /path/to/workspace
python -m makora_core skills
```

Поместите документ или извлечённый текст в `input/`, затем зарегистрируйте и явно подтвердите его:

```sh
python -m makora_core register /path/to/workspace INPUT-001 input/brief.txt text
python -m makora_core approve /path/to/workspace INPUT-001 --note "Проверен исходный документ"
python -m makora_core prepare /path/to/workspace requirements-analysis --artifact INPUT-001 --task "Разобрать задание" --output requirements.yaml --success "Подтверждённые требования имеют источники"
```

`prepare` возвращает пакет вызова и статус `not_started`; он не запускает скилл и не анализирует документ. `register` регистрирует существующий файл в `input/` или `artifacts/`, поддерживает `--depends-on ID` и `--source` многократно. `audit` сравнивает содержимое файлов с сохранёнными версиями и помечает зависимые результаты как требующие перепроверки. `approve` фиксирует решение; подтверждённый результат можно передать в `prepare`.

Снимки файлов сохраняются в `state/versions/`, история решений и зависимости — в `state/manifest.json`. Система рассчитана на одного локального исполнителя: блокировка для одновременной записи пока не реализована. Для PDF и изображений требуется доступный инструмент извлечения текста; автоматически извлекать их модуль не умеет.
