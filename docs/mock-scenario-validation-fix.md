# Проверка реального этапа моков, 1 ноября 2026

Первоначальная ошибка `Нет сценариев фикстур` возникала потому, что
`mocks/scenarios.json` содержал `scenariosFile`, а контроллер ожидал только
массив `scenarios`. В исходном пакете также пять негативных сценариев
проверяли валидный контейнер вместо отдельного некорректного payload.

Контроллер теперь читает локальные индексы сценариев, отклоняет циклы и
внешние ссылки, поддерживает JSON Pointer для данных и `$defs` для схем.
Ошибка проверки сохраняет созданные файлы для просмотра. Текст ошибки
отображается без JSON-кавычек.

После исправления контроллера через публичный API запущена одна новая
сессия GPT-6 Luna с замечаниями к мокам. Артефакты вручную не редактировались.

- Thread: `01a193cc-655a-72a1-a159-38d101da4aaa`
- Turn: `01a193cc-78f4-73b3-932e-6fac9123c3b0`
- Результат: 9 файлов, 29 проверок контроллера, 0 ошибок.
- Статус этапа: `review`, требуется утверждение пользователя.
- Первые три утверждённых этапа сохранены.

29 проверок включают наличие обязательных файлов, реальные проверки
сценариев по JSON Schema и наличие моков для утверждённых задач.
Это не исполнение тестов приложения и не утверждение этапа автоматически.

Регрессии: `tests/test_preparation.py`. Проверяются локальный индекс,
циклические/внешние ссылки, ссылки на payload и определения схем,
ожидаемая невалидность данных и сохранение файлов при ошибке.
