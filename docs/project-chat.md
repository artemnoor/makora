# Чат с Макорой

Кнопка «Поговорить с Макорой» находится у персонажа. Обычные вопросы отправляются в отдельный read-only Codex thread на GPT-6 Luna. Условие, документы и состояния этапов передаются как контекст; дальнейшие сообщения продолжают тот же thread с актуальным снимком проекта. Разговор не запускает разработку и не утверждает документы. Правки применяются отдельными действиями интерфейса.

При выбранной папке история сохраняется в `reports/chat.json`, `reports/chat.md` и в состоянии `.makora/preparation/state.json`. Пока ответ не подтверждён, новая отправка блокируется. Request ID предотвращает повторную доставку одного сообщения. Ответ сопоставляется с точным turn ID; старый ответ из истории не принимается за новый. После неоднозначной доставки автоматически повторять запрос нельзя.

Индикатор колеса используется на этапах 1–4 во время подготовки документов и на этапах 5–6 при активных реальных сессиях. Его положение сохраняется между обновлениями интерфейса. При запросе разрешения вращение приостанавливается и предлагается открыть запрос.
