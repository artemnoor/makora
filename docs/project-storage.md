# Папка проекта

Перед первым анализом интерфейс требует выбрать пустую папку стандартным диалогом операционной системы. Отмена сохраняет текущий проект. Непустая папка отклоняется, существующие файлы не изменяются. Кнопка папки справа вверху открывает выбранный каталог в Проводнике Windows.

```text
папка проекта/
├── PROJECT.md
├── input/
│   ├── original/             # Исходный PDF, DOCX, TXT или MD без изменения байтов
│   ├── attachments/          # Файлы уточнений
│   └── brief.txt             # Текст, переданный на анализ
├── artifacts/               # MD, Mermaid, контракты, задачи и mocks/
├── app/                     # Приложение, моки и Git-история; создаётся на этапе 5
├── reports/
│   ├── stage-N-checks.json
│   └── agents.json          # Сессии, результаты, тесты, Reviewer, события
├── exports/project-context.zip
└── .makora/
    ├── preparation/         # Состояние, INPUT.json и result.json всех генераций
    └── agents/              # Контекст планировщика и изолированные Git worktree
```

Служебный указатель текущего проекта остаётся в исходном workspace Макоры; состояние подготовки также сохраняется в выбранной папке. Регистрация папки приложения сохраняется в runtime, поэтому после перезапуска новые worktree и отчёты продолжают попадать в тот же проект. Старые проекты сохраняют прежнее расположение; новая папка не переносит и не удаляет их автоматически. Системные данные Codex и секреты авторизации не копируются в проект.

Маршруты выбора, открытия и загрузки защищены текущей same-origin авторизацией локального API. Сайт не передаёт произвольный путь для выбора или открытия: сервер принимает результат собственного нативного диалога. Запись артефактов проверяет границы папки и символические ссылки.

Проверки: `tests/test_preparation.py`, тест runtime `test_project_storage_keeps_worktrees_and_reports_with_project`, браузерный `tests/browser-project-folder.js`. Браузерный тест использует подмену HTTP и не открывает пользовательские диалоги. Python-тесты создают настоящие временные файлы и Git worktree с fake-provider.
