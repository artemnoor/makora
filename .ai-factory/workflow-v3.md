# Новый конвейер Макоры

- [x] Новый порядок и безопасный перенос сохранённых проектов без удаления документов.
- [x] Короткое объяснение; ограничения только с цитатами исходного кейса.
- [x] Брейншторм в Desktop: идея → «готово» → версии и экраны → подтверждение → публикация.
- [x] Моки до пакета; планирование после возвращённого проекта.
- [x] Редактируемый DAG: общий каркас, основные задачи, добровольные лаборатории, моки до приёмки.
- [x] Изоляция лабораторий, мини-интерфейсы для проверки, человеческая приёмка и исключение тестового UI при интеграции.
- [x] Навыки, регрессионные и браузерные проверки.

Публикация и обновление установленного проекта выполняются после зелёного CI; доказательство хранится в PR и GitHub Actions.

Старые числовые API-ID сохраняются: порядок доски [0,2,3,5,6,4,7]. Старый анализ задания хранится только как история. Конвейер v2 остаётся совместимым для чтения прежних артефактов и тестов; действующий сервер использует v3.
