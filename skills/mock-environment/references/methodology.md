# Правила данных и моков

Не добавляй поля API без согласованного контракта. Сохраняй связи между объектами и ясное происхождение синтетических значений; не используй персональные данные без надлежащего основания. Для воспроизводимого генератора фиксируй seed и версию библиотеки. Поле времени и его свежесть проверяй относительно контролируемого времени, если сценарий должен быть стабильным.

Фикстуры не являются реализацией бизнес-логики. Сценарии ошибок должны соответствовать контракту и их отрицательный результат должен быть ожидаемым. Сетевую заглушку не запускай при отсутствии потребности; явно отделяй проверку локальной заглушки от проверки реального backend.
