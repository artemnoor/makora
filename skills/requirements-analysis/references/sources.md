# Источники методологии

- [NASA: Requirements Verification Matrix](https://www.nasa.gov/reference/appendix-d-requirements-verification-matrix/) — идентификаторы, источники и проверка обязательных требований.
- [NASA: Requirements Management](https://www.nasa.gov/reference/6-2-requirements-management/) — связи и управление изменениями требований.
- [Atlassian: Prioritization Frameworks](https://www.atlassian.com/agile/product-management/prioritization-framework/) — способы приоритизации; приоритет команды не заменяет обязательность по ТЗ.
- [GOV.UK: Learning about users and their needs](https://www.gov.uk/service-manual/user-research/start-by-learning-user-needs) — разделение потребностей пользователей и решений.
- [Superpowers: Brainstorming](https://github.com/obra/superpowers/blob/main/skills/brainstorming/SKILL.md) — работа с неопределённостью; не применять этап проектирования решения внутри анализа ТЗ.
