# Правила выбора и сценариев

Проверяй каждый вариант на совместимость с обязательными требованиями и прямыми запретами прежде, чем сравнивать его. В таблице решения разделяй факты, субъективные оценки и неизвестные значения. Отсутствие API или набора данных не означает его существование или бесплатность.

User flow — общий путь роли к цели с точками выбора и альтернативами. Task flow — конкретная последовательность действий для одного результата, с входами и условиями завершения. Идентифицируй сценарии, которые позже попадут в тест-план и подготовку данных. На диаграммах не добавляй функции вне MVP.

Метрики должны иметь единицу, способ и контекст измерения. Отмечай цели как гипотезы до фактического тестирования. Демо-сценарий не доказывает работоспособность продукта до выполнения.
