# Макора — установка в проект Codex

Если пользователь скачал этот репозиторий для управления своим проектом, установи Макору командой `./setup.ps1 -ProjectRoot <папка проекта Codex>` из корня репозитория. Если репозиторий находится в подпапке `makora`, папка проекта — её родитель; если скачан в корень проекта — корень репозитория. Используй явно заданную пользователем папку при наличии.

Установщик создаёт `.makora/control.json`, добавляет проектные навыки в `.agents/skills`, дополняет AGENTS.md и запускает локальный сайт. Не создавай дополнительный проект в Desktop. Не копируй токены или авторизацию в репозиторий. После установки прочитай `<projectRoot>/.agents/skills/makora-control/SKILL.md` и проверь `status` контроллером. Все дальнейшие действия из Codex и сайта должны обращаться к одному проекту.

Для разработки самой Макоры: Python-модули в `makora_core/`, сайт в `dist/`, методические навыки в `skills/`, проверки в `tests/`. Запуск тестов: `python -m unittest discover -s tests -q`. Не публикуй `.makora/`, `output/`, окружения, личные документы и секреты.
